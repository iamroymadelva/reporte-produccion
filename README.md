# Reporte Diario de Producción y Mantenimiento

Aplicación web para digitalizar el reporte diario de producción y mantenimiento de la empresa.

## Stack

- Astro con renderizado en servidor
- Tailwind CSS
- React para islas interactivas
- Adaptador oficial de Vercel
- Supabase PostgreSQL y Auth en una fase posterior

## Desarrollo local

Instala las dependencias y ejecuta el servidor de desarrollo:

```sh
bun install
bun run dev
```

## Compilación

```sh
bun run build
```

La interfaz dirigida a usuarios se desarrolla completamente en español. La conexión y configuración de Supabase se implementarán en una fase posterior.
